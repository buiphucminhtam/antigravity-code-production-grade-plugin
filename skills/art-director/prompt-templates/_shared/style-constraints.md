# Contract-Bound Style Inputs

Use this shared block as a prompt compiler input. It supplies structure without
inventing a palette, type system, composition, or motion language. Every value
must come from the approved Style DNA, assigned reference roles, a measured drift
finding, or a production/platform requirement.

## Direction inputs

- **Approved Style DNA:** [APPROVED_STYLE_DNA]
- **Reference-role map:** [REFERENCE_ROLE_MAP]
- **Asset family:** [ASSET_FAMILY]
- **Real-scale context:** [REAL_SCALE_CONTEXT]
- **Platform and production constraints:** [PLATFORM_AND_PRODUCTION_CONSTRAINTS]
- **Observed or credible drift:** [OBSERVED_OR_CREDIBLE_DRIFT]

## Bind only approved decisions

- **Color roles and progression:** [COLOR_ROLES_AND_PROGRESSION]
- **Typography or lettering system:** [TYPOGRAPHY_SYSTEM]
- **Spacing and geometry tokens:** [SPACING_AND_GEOMETRY_TOKENS]
- **Material, edge, and shadow behavior:** [MATERIAL_EDGE_SHADOW_RULES]
- **Lighting and atmosphere:** [LIGHTING_AND_ATMOSPHERE_RULES]
- **Motion and state behavior:** [MOTION_AND_STATE_RULES]
- **Responsive and accessibility rules:** [RESPONSIVE_ACCESSIBILITY_RULES]
- **Output and import contract:** [OUTPUT_IMPORT_CONTRACT]

Do not derive a fixed color count, font preference, radius, grid, shadow, timing
scale, breakpoint, or contrast treatment from this template. Record any
prohibited drift as `[PROHIBITED_DRIFT]` with its evidence. If a dimension is
not applicable or not yet approved, mark it `[OPEN_STYLE_DECISION]` and route it
to a style-frame or production test before generation.

## Non-default examples

The following values are **non-default examples** only: a 4px spacing unit, a
small/medium/large radius scale, a 44×44px touch target, or a 150ms hover
transition. Retain any one only when the platform contract or approved Style DNA
explicitly requires it, and replace it with the actual token.
